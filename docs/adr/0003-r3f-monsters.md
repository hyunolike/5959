# ADR-0003 R3F 코드 생성 3D 몬스터

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

원본 캐릭터 그림은 LICENSE가 없는 팀 저장소에 있다. 공개 포트폴리오에서 그대로 쓰기 어렵다.
원본은 감정마다 크기별 그림과 처치된 그림을 따로 그려서, 상태가 늘어날수록 그림도 늘어나는 구조였다.

## 결정

React Three Fiber로 몬스터를 코드로 만든다. 감정 5종이라는 개념만 이어받는다.

- 외형은 `(감정, HP 비율, 상태) → 외형 파라미터` 순수 함수로 계산한다. 그림을 따로 그리지 않아도 상태가 곧 모습이 된다.
- 글 상세와 레이드 화면에서만 3D로 렌더링하고, 목록에서는 빌드 때 캡처한 정지 이미지를 쓴다.
- WebGL을 쓸 수 없거나 모션 줄이기 설정이 켜져 있으면 정지 이미지로 대체한다.

## 검토한 대안

- **원본 그림 사용**: 디자이너와 팀의 동의가 필요하고, 상태가 늘 때마다 그림을 새로 그려야 한다.
- **AI 3D 생성(Meshy, Tripo)**: 퀄리티는 높지만 5종의 스타일을 맞추기 어렵고, HP에 따른 변화는 따로 만들어야 한다.
- **Spline 직접 제작**: 디자인에 드는 시간이 가장 크다.

## 결과

- 저작권 문제가 없다.
- 레이드 보스 같은 새 상태를 파라미터만으로 추가할 수 있다.
- 아트 완성도는 전문 디자이너의 그림에 못 미치므로, 단순하고 귀여운 스타일로 방향을 잡는다.
- Three.js 번들이 커서 동적 import와 페이지 분리가 필수다.
