# ADR-0004 VM 내 PostgreSQL

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

월 인프라 비용 0원이 목표다. pgvector가 필요하고, 채용 담당자가 언제 접속해도 서비스가 바로 응답해야 한다.
백엔드 서버는 Oracle Cloud 무료 ARM VM(서울 또는 춘천 리전)에 둔다.

## 결정

PostgreSQL 17과 pgvector를 같은 VM의 Docker Compose로 운영한다.

- 매일 `pg_dump`를 Cloudflare R2에 올리고 14일간 보관한다.
- 복구 절차를 `infra/RESTORE.md`에 적고, 분기마다 실제로 복구해 본다.

## 검토한 대안

- **Neon 무료**: 서울 리전이 없어 쿼리마다 해외 왕복 지연이 붙는다.
- **Supabase 무료**: 서울 리전은 있지만 일주일 동안 쓰지 않으면 프로젝트가 일시 중지된다.
- **AWS RDS**: 무료 기간이 끝나면 비용이 생긴다.

## 결과

- 지연과 일시 중지 문제가 없다.
- 백업, 업그레이드, 디스크 관리를 직접 해야 한다.
- VM이 회수되면 DB도 함께 사라지므로 백업과 복구 연습이 필수다.
