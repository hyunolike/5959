# 서버 대기 중 응원 방울 모으기

상태: 이전 구현 기록. 이후 사용자가 승인한 [마음 산책 러너](2026-11-13-ogu-walk-runner-design.md)로 대체했다.

2026-11-13 검토에서 제안한 응원 방울 모으기를 사용자가 진행 승인했다.

## 목적과 범위

서버를 기다리는 사람이 선택해서 짧게 놀 수 있게 한다. 로그인과 가입의 기존 입력 및 자동 제출, 회원 화면 복구를 유지한다. 미니게임으로 서버 준비 시간을 단축하거나 준비율을 나타내지 않는다.

## 검토한 접근

- 몬스터 연타: 레이드와 연결되지만 반복 입력 부담과 실제 공격 혼동이 있다.
- 응원 방울 모으기(선택): 다정한 캐릭터와 간단한 조작을 함께 살린다.
- 호흡 맞추기: 분위기는 어울리지만 게임으로서의 반응이 약하다.

## 동작

- 서버가 `waking`일 때만 시작 버튼을 제공한다. 자동으로 시작하지 않는다.
- 한 판은 25초다. 여섯 개의 큰 방울에 응원 문구를 담고, 누르면 오구에게 모인다. 놓침, 감점, 순위, 저장 보상은 없다.
- 한 방울은 한 번만 수집되며 잠시 뒤 돌아온다. 종료 후 반복하거나 닫을 수 있다.
- 준비 완료 시 수집과 새 판을 중단한다. 진행 중이던 회원 화면에서는 완료 안내를 최대 1.2초 보인 뒤 자동 복귀하며 즉시 계속하기도 가능하다. 이미 제출한 인증 요청은 기존대로 바로 진행한다.
- 7분 연결 실패 시 놀이를 멈추고 기존 실패 안내와 재연결 경로를 우선한다.
- 브라우저에서만 실행한다. 서버 요청, 점수 저장, 새 의존성은 추가하지 않는다.

## 시각과 접근성

기존 Pretendard, 역할 색상, 모서리, Button, Phosphor, LazyMotion의 `m`과 움직임 줄이기 훅을 사용한다. 기존 오구 그림을 재사용한다. 노란 게임 버튼과 감정 색을 장식용으로 확대하지 않는다. 방울은 48px 이상의 실제 버튼이며 키보드 조작을 제공한다. 경과 초와 게임 점수 전체를 반복 낭독하지 않는다. 소리는 없다. 320px 화면에서 가로 넘침이 없어야 한다.

## 확인

선택 시작, 중복 수집 방지, 25초 종료 및 반복, 준비 완료와 실패 시 중단, 재연결, 인증 자동 제출과 초안 보존을 테스트한다. 모바일과 데스크톱에서 게임과 복구 화면을 직접 확인한다. 도입 효과는 추후 대기 진입 대비 원래 작업 도달률로 평가한다.
