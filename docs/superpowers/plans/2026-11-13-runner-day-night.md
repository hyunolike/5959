# 산책 낮과 밤 Implementation Plan

**Goal:** 사용자가 요청한 낮/밤 반복을 기존 게임에 추가한다.
**Design:** 한 판의 실제 플레이 시간을 따라 낮 20초, 해질녘 4초, 밤 20초, 새벽 4초를 반복한다. 멈추면 하늘도 멈추며 재시작하면 낮으로 돌아온다. 움직임 줄이기는 중간 색 없이 전환한다. 기존 역할 토큰의 밝은 면과 잉크/흰색을 사용하고 해와 달, 고정된 별을 Canvas 기본 도형으로 표현한다.
**Approach:** 기존 Canvas 렌더러에서 계산하고 그린다. 앱 전체 테마를 바꾸거나 캐릭터 자산을 추가하지 않는다. 밤의 안내와 키보드 초점 대비를 유지한다. 기존 속도 증가와 물리 판정은 그대로 사용한다.

- [x] 순수 하늘 주기 계산의 반복, 전환, 움직임 줄이기 테스트를 먼저 작성하고 실패 확인.
- [x] Canvas 팔레트에 기존 역할 토큰의 밤 색을 연결하고 해/달/별, 배경과 길의 점진적 전환 구현.
- [x] 안내와 초점의 대비, 일시정지와 재시작 확인.
- [x] 웹 단위 테스트, 타입/린트/FSD, 완전한 프로덕션 빌드와 낮/밤 브라우저 캡처 확인.

사용자의 추가 지시에 따라 기존 체크아웃에서 구현한다. 앞선 미커밋 작업을 보존하고 커밋/배포하지 않는다. 빌드는 샌드박스 밖에서 실행하고 `middleware.js` 및 standalone 산출물을 함께 확인한다.

## 검증 결과

- 전체 웹 테스트 173개 파일, 1,658개 통과. 하늘 주기/보간/움직임 줄이기 12개 추가.
- 브라우저 7개 시나리오 통과. 실제 점프 입력으로 50초 산책을 진행해 Canvas가 낮(255,255,255) → 밤(23,23,28) → 낮으로 변하는지 확인했다. 밤의 일시정지 시 색이 유지되며 재개 후 다음 주기로 진행한다.
- 타입 검사, 포맷과 FSD 통과. ESLint 오류 없음(기존 query-client 경고 1건). 프로덕션 Webpack 빌드와 최종 middleware/standalone 생성 확인.
- 별도 코드 리뷰에서 중요한 버그 없음. 밤 플레이와 일시정지 스크린샷으로 캐릭터, 길, 초점, 안내의 대비를 확인했다.
- 최신 로컬 미리보기를 3030 포트에 다시 띄웠다. 배포하지 않았다.
