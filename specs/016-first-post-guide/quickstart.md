# Quickstart: 첫 글로 이어지는 안내 검증 (016-first-post-guide)

## 출시 전에 기준값 적기

출시하기 전에 지난 4주의 값을 이 표에 적는다. SC-001, SC-003, SC-004는 이 값과 견준다.

| 기준 | 재는 법 | 출시 전 4주 | 출시 뒤 4주 |
|---|---|---|---|
| SC-001 가입한 날 첫 글 비율 | DB: 가입 시각과 같은 날(한국 시간) 첫 글이 있는 회원 / 그 기간 가입 회원 | | |
| SC-003 쓰기 화면 이탈 | DB의 기간 내 글 작성 수 ÷ Umami의 `/write` 방문 수 | | |
| SC-006 첫 화면 표시 시점 | 운영 `/`를 Lighthouse(모바일)로 세 번 재어 LCP 중앙값 | | |
| SC-004 첫 글 뒤 일주일 재방문 | DB의 첫 글 시각 뒤 7일 안의 로그인 갱신 | | |

## 자동 검증

```bash
pnpm --filter web typecheck && pnpm --filter web lint && pnpm --filter web lint:fsd
pnpm --filter web test            # US1~US5 단위 테스트, 011 US3-AC1 갱신분
pnpm --filter web test:e2e        # landing.spec.ts, guest-home.spec.ts
pnpm --filter web test:e2e:full   # first-post-guide.spec.ts(새로), signup-onboarding.spec.ts, write-post.spec.ts
pnpm --filter web build
```

## 수동 검증 (로컬)

| # | 절차 | 기대 결과 | 인수 조건 |
|---|---|---|---|
| 1 | 새 이메일로 가입하고 온보딩을 연다 | 직군과 경력 아래 쓰는 까닭과 "이름과 회사는 묻지 않아요" | US2-AC1 |
| 2 | 온보딩을 마친다 | `/home` 맨 위에 환영 안내, 첫 고민 카드는 없음 | US2-AC2 |
| 3 | 새로 고친다 | 환영 안내 대신 첫 고민 카드 | US2-AC5, US2-AC6 |
| 4 | 카드를 닫고 새로 고친다 | 카드가 없다 | US2-AC8 |
| 5 | 글을 보려다 로그인한 새 계정으로 온보딩을 마친다(`/post/1`에서 시작) | 그 글로 가고 환영 안내는 없다 | US2-AC4 |
| 6 | `/write`를 연다 | 공개 범위 세 줄 묶음, 실마리 칩, 공개 범위를 다르게 말하는 문장 없음 | US1-AC1~AC3 |
| 7 | 실마리를 누르고 이어 쓴 뒤 다 지운다 | 문장이 들어가고 초점이 간다. 다 지우면 칩이 다시 보인다 | US1-AC4, US1-AC5 |
| 8 | 말투를 차례로 고른다 | 예시 한 줄이 바뀐다 | US1-AC6 |
| 9 | 첫 글을 올린다 | 글 화면에 첫 글 안내. 몬스터가 나타나면 보이는 글자로 알림. 주소에 `?first=1`이 남지 않음 | US3-AC1, US3-AC2 |
| 10 | 새로 고친다 | 첫 글 안내가 없다 | US3-AC4 |
| 11 | 두 번째 글을 올린다 | 첫 글 안내가 없다 | US3-AC3 |
| 12 | 위기 표현이 있는 첫 글을 올린다(새 계정) | 도움 안내만 있고 첫 글 안내는 없다 | US3-AC5 |
| 13 | 다른 회원의 글, 내 글, AI 친구 글을 연다 | "나도 털어놓기"는 다른 회원과 AI 글에만 | US4-AC1~AC3 |
| 14 | 로그아웃하고 `/`와 `/home`을 연다 | 사용법 자리의 시각 자료가 8초 안에 돌고 반복. `/home`은 사용법이 최근 이야기보다 위 | US5-AC1, US5-AC4, US5-AC5 |
| 15 | 개발자 도구에서 `prefers-reduced-motion: reduce`를 켠다 | 세 칸이 멈춘 그림으로 나란히 | US5-AC2 |
| 16 | 몬스터 그림 요청을 막고 `/`를 연다 | 글로 쓴 사용법은 그대로 | US5-AC6 |
| 17 | 휴대폰 크기(375px)로 6, 9, 14를 다시 본다 | 가로 스크롤 없음 | — |
