# Quickstart: 몬스터 도감 검증 (010-monster-cards)

구현이 끝난 뒤 기능이 처음부터 끝까지 동작하는지 확인하는 절차다. 계약은 [contracts/monster-cards.openapi.yaml](contracts/monster-cards.openapi.yaml), 데이터는 [data-model.md](data-model.md), 결정 근거는 [research.md](research.md)를 본다.

## 준비

```bash
cd apps/api && SPRING_PROFILES_ACTIVE=local,e2e ./gradlew bootRun
pnpm --filter web dev
```

e2e 프로필의 가짜 감정 분석은 본문 머리말로 감정과 세기를 정한다. `[불안:낮음]`은 HP 10, `[불안:보통]`은 20, `[불안:높음]`은 30이다. 공감은 1, 회원마다의 첫 댓글은 3을 줄인다. HP 10인 몬스터는 회원 셋이 공감과 댓글을 하나씩 남기면 처치된다.

## 자동 검증

```bash
cd apps/api && ./gradlew test --tests "*MonsterCard*"
pnpm --filter web test
pnpm --filter web test:e2e               # monster-cards.spec.ts(가짜 API)
pnpm --filter web test:e2e:full          # monster-cards.spec.ts(실제 API)
```

## 수동 검증 시나리오 (로컬)

회원 A, B, C, D가 가입과 온보딩을 마친 상태에서 시작한다.

| # | 절차 | 기대 결과 | 인수 조건 |
|---|---|---|---|
| 1 | A가 `[불안:낮음]` 글을 쓰고 B, C, D가 공감과 댓글을 하나씩 남긴다 | A의 도감에 "내 몬스터" 카드 한 장. B, C, D의 도감에 "함께 물리침" 카드 한 장씩 | US1-AC1, US1-AC2, US1-AC9 |
| 2 | A가 글을 하나 더 쓰고 B만 공감한다 | 누구의 도감에도 그 카드가 없다 | US1-AC3 |
| 3 | 1번의 글에 새 회원 E가 공감한다(이미 처치됨) | E의 도감에 카드가 없다 | US1-AC4 |
| 4 | 1번의 카드를 본다 | 처치된 불안 몬스터의 그림, "불안", 카드 번호, "일반", 물리친 날 | US2-AC1 |
| 5 | `[짜증:보통]`, `[외로움:높음]` 글을 처치한다 | 등급이 희귀, 전설이고 글자로 적혀 있다. 반짝임이 다르다 | US2-AC2, US3-AC3 |
| 6 | B가 1번의 카드를 크게 본다 | "내가 준 피해 4". 본문과 A의 닉네임이 없다 | US2-AC3, US2-AC5 |
| 7 | A가 1번의 카드를 크게 본다 | "함께 물리친 회원 3명". 누구인지는 없다 | US2-AC4 |
| 8 | 크게 본 카드에서 "글 보기"를 누른다 | 그 글의 상세로 간다 | US2-AC6 |
| 9 | 카드를 누르고 손가락이나 마우스를 움직인다 | 카드가 기울고 빛이 따라온다 | US3-AC1, US3-AC2 |
| 10 | 기기의 움직임 줄이기를 켜고 9번을 한다 | 기울지 않고 빛이 멈춰 있다 | US3-AC4 |
| 11 | 키보드로 카드를 열고 Esc로 닫는다 | 초점이 대화상자 안에 머물고, 닫으면 열었던 카드로 돌아온다 | US3-AC5 |
| 12 | 320px 너비에서 카드를 크게 본다 | 넘치지 않는다 | US3-AC6 |
| 13 | 도감 위를 본다 | 모은 수와 감정별 장수. 없는 감정은 빈 자리 | US4-AC1, US4-AC2 |
| 14 | 감정 하나를 누르고 다시 누른다 | 그 감정의 카드만 보였다가 모두 보인다. 위의 숫자는 그대로다 | US4-AC3 |
| 15 | A가 1번의 글을 지운다 | A, B, C, D의 도감에서 그 카드가 빠진다 | US1-AC7 |
| 16 | 운영자가 5번의 글 하나를 숨겼다가 푼다 | 카드가 빠졌다가 돌아온다 | US1-AC7 |
| 17 | 카드가 없는 회원이 도감을 연다 | 카드를 얻는 방법과 글쓰기, 피드로 가는 길 | US1-AC6 |
| 18 | 로그인하지 않고 `/cards`를 연다. 홈의 메뉴에서 도감을 누른다 | 로그인 화면으로 간다. 메뉴는 로그인 안내를 연다 | US1-AC8, US5-AC4 |
| 19 | 좁은 화면과 넓은 화면의 메뉴를 본다 | 이야기, 함께, 고민 쓰기, 도감, 기록. 좁은 화면에서 고민 쓰기가 한가운데 | US5-AC1, US5-AC2, US5-AC3 |

`US1-AC5`(쪽 나누기), `US2-AC7`(번호와 등급이 그대로), `US4-AC4`(낭독)는 자동 테스트가 본다.
