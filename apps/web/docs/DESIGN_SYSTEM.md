# 오구오구 디자인 시스템

직장인의 고민을 나누고 공감으로 감정 몬스터를 함께 물리치는 커뮤니티다. 피드의 가독성을 먼저 확보하고, 캐릭터와 라일락 색으로 편안한 분위기를 만든다. 실제 데이터와 기존 서비스 기능을 그대로 사용한다.

## 색과 타이포그래피

토큰 정본은 `src/core/styles/globals.css`다. 기존 화면의 neutral 유틸리티도 같은 보라빛 회색으로 연결한다.

| 역할                   | 토큰        | 값      |
| ---------------------- | ----------- | ------- |
| 페이지 배경            | background  | #faf9fc |
| 카드와 입력 중인 필드  | white       | #ffffff |
| 제목과 본문            | neutral-900 | #291c38 |
| 보조 설명              | neutral-600 | #645572 |
| 부가 정보              | neutral-500 | #796d89 |
| 기본 테두리            | neutral-200 | #e2dce9 |
| 선택 배경              | brand-50    | #f1ebfb |
| 주요 버튼과 포커스     | brand-600   | #7655b4 |
| 강조 글자와 버튼 hover | brand-700   | #614095 |

본문 폰트는 Spoqa Han Sans Neo다. Regular 400과 Bold 700 WOFF2를 `next/font/local`로 자체 호스팅한다. 제목은 24px, 인증 소개 제목은 모바일 32px와 데스크톱 42px, 본문은 14–16px, 보조 정보는 12px를 기본으로 한다. 본문 줄 간격은 1.65이며 긴 고민 글은 1.75 이상으로 읽기 쉽게 배치한다.

## 레이아웃과 컴포넌트

- 전체 너비는 최대 1200px다. 로그인 이후 데스크톱에는 왼쪽 탐색 메뉴, 홈의 넓은 화면에는 오른쪽 공감 안내를 둔다. 모바일에는 안전 영역을 고려한 고정 하단 메뉴를 제공한다.
- `widgets/app-shell`은 탐색과 본문 건너뛰기를 담당한다. 알림은 루트 레이아웃이 슬롯으로 전달해 위젯 사이의 의존성을 만들지 않는다. 로그인과 온보딩을 완료해야 회원 메뉴를 표시한다.
- `widgets/auth-welcome`은 로그인, 가입, 온보딩에서 같은 소개와 캐릭터를 제공한다. 모바일에서는 폼을 우선해 큰 그림을 숨긴다.
- 버튼과 입력은 12px, 카드는 16px, 안내 패널은 16–24px 모서리를 사용한다. 버튼 기본 높이는 44px, 입력 높이는 48px다. 주요 콘텐츠 간격은 24px이고 컴포넌트 안에서는 8–16px 간격을 사용한다.
- 공감에는 Heart, 댓글에는 MessageCircle, 작성에는 PencilLine, 알림에는 Bell 아이콘을 사용한다. 아이콘은 Lucide의 1.8–2px 선 두께로 통일한다. 텍스트와 함께 있는 장식 아이콘은 `aria-hidden` 처리한다.
- 피드 카드는 글 상세로 연결되는 하나의 링크다. 카드 안에 작동하지 않는 공감 버튼을 배치하지 않는다. 실제 공감은 상세 화면에서 처리한다.

## 상호작용과 접근성

선택한 메뉴는 `aria-current`, 필터와 댓글 말투 및 공감 선택은 `aria-pressed`로 상태를 전달한다. 메뉴의 하위 경로에서도 상위 메뉴를 표시한다. 필터 상태는 URL에 남아 뒤로 가기와 새로고침에 유지된다.

버튼을 누르면 짧게 크기가 줄고, hover와 키보드 포커스에는 색과 테두리가 반응한다. 요청 중에는 기존 중복 제출 방지를 유지한다. `prefers-reduced-motion`에서는 이동과 애니메이션을 최소화한다. 빈 피드에는 실제 상황에 맞는 안내와 작성 링크를 제공하고, 오류에는 기존 오류 메시지를 유지한다. OS 다크 모드 때문에 밝은 카드와 검은 배경이 섞이지 않도록 서비스 전체를 라이트 테마로 통일한다.

알림 토스트는 화면을 기준으로 배치하고 모바일 하단 메뉴와 안전 영역 위에 표시한다. 헤더의 흐림 효과는 별도 배경 레이어에 두어 고정 위치의 알림을 헤더 안에 가두지 않는다.
